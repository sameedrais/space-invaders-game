# Space Invaders Game 🎮

A classic **Space Invaders–style 2D game** developed in **C++ using Raylib**, designed as an Object-Oriented Programming (OOP) course project.  
The game focuses on smooth gameplay, clean object-oriented design, and fundamental game development concepts such as collision detection, game loops, and state management.

---

## 📌 Project Overview

This project is a recreation of the classic *Space Invaders* arcade game. The player controls a spaceship that can move horizontally and shoot lasers to destroy waves of incoming aliens. The game includes obstacles for defense, multiple enemy types, scoring mechanics, sound effects, and background music to enhance the gameplay experience.

The game is built using the **Raylib** library, which simplifies graphics rendering, input handling, and audio management in C++.

---

## ✨ Key Features

- **Smooth Graphics & Animation**
  - Custom textures for spaceships, aliens, and obstacles
  - Resolution-aware positioning for consistent display
  - Smooth movement and laser animations

- **Sound & Music**
  - Continuous background music
  - Sound effects for laser firing and explosions

- **Game Mechanics**
  - Player-controlled spaceship (move left/right, shoot lasers)
  - Multiple alien types with different score values
  - Alien laser attacks
  - Destructible obstacles
  - Mystery ship that appears randomly for bonus points

- **Game States**
  - Running and Game Over states
  - Restart option using the **Enter** key
  - Lives system with visual indicators
  - Score and High Score display

- **File Handling**
  - High score is saved and loaded using file I/O for persistence

---

## 🧠 Object-Oriented Programming Concepts Used

- **Classes & Objects**
  - Spaceship, Alien, Laser, Obstacle, MysteryShip, and Game classes

- **Encapsulation**
  - Internal data hidden using private members with public interfaces

- **Abstraction**
  - Complex logic (movement, firing, collision checks) handled through simple method calls

- **Composition**
  - The `Game` class manages and coordinates all game entities

---

## 🛠️ Technologies Used

- **Language:** C++
- **Library:** Raylib
- **Concepts:**  
  Game Loop, Collision Detection, Event Handling, State Management, File I/O, Timers, Randomization

## 🚀 How to Set Up the Project

Follow these steps to run the project on your system:

1. Visit the official Raylib website:  
   👉 https://www.raylib.com/

2. Click on **Download**.

3. When redirected, click on  
   **“No thanks, just take me to the downloads”**.

4. Download the Raylib installer suitable for your operating system.

5. Run the downloaded executable and **install Raylib**.

6. Unzip the project folder.

7. Open the project workspace (main file).

8. Press **F5** to build and run the game.
